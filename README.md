---

# 📖 About WealthWise

WealthWise is a women-centric financial literacy platform designed to simplify personal finance through smart budgeting, savings planning, AI-powered guidance, financial education, and a supportive community.

The platform empowers users to build healthy financial habits, achieve savings goals, improve financial knowledge, and learn from real stories shared by other women.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/Rao11falakyadav/WealthWise.git
```

## Navigate to Project

```bash
cd WealthWise
```

## Install Dependencies

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```

Open:

```text
http://localhost:5173
```
